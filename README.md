# Northstar Studio

Современный многостраничный сайт независимой digital-студии Northstar Studio. Проект представляет услуги агентства, демонстрирует портфолио и помогает потенциальным клиентам связаться со студией.

## Ссылки

- **Демо сайта:** [northstar-studio-redesign.vercel.app](https://northstar-studio-redesign.vercel.app/)
- **Репозиторий:** [github.com/EgorProjects/northstar-studio-redesign](https://github.com/EgorProjects/northstar-studio-redesign)

## Обзор

Сайт включает главную страницу, страницу о студии, услуги, портфолио с фильтрами, контакты с демонстрационной формой и страницу 404. Интерфейс адаптирован для мобильных устройств, использует общую навигацию, доступные интерактивные состояния и отдельные SEO-метаданные для страниц.

Портфолио и профили команды демонстрационные. Форма проверяет ввод на стороне клиента, но пока не отправляет и не сохраняет данные.

## Технологии

- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- Vercel

## Локальный запуск

```bash
npm install
npm run dev
```

Затем откройте адрес, который выведет Next.js в терминале.

## Команды

- `npm run dev` — сервер разработки.
- `npm run lint` — ESLint.
- `npm run typecheck` — проверка TypeScript.
- `npm run build` — production-сборка.
- `npm run start` — запуск production-сборки.

## Перед использованием в коммерческом проекте

- Заменить концепт-проекты подтверждёнными кейсами.
- Указать реальные профили команды либо убрать демонстрационные карточки.
- Заменить `hello@northstar.example` и домен `northstar.example` на рабочие контакты.
- Подключить backend для приёма заявок, если нужна реальная отправка формы.
