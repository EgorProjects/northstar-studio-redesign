# Northstar Studio

Демо-фронтенд digital-студии на Next.js App Router, React, TypeScript и Tailwind CSS.

## Запуск

```bash
npm install
npm run dev
```

Откройте <http://localhost:3000>.

## Скрипты

- `npm run dev` — локальный сервер разработки.
- `npm run lint` — ESLint.
- `npm run typecheck` — проверка типов TypeScript.
- `npm run build` — production-сборка.
- `npm run start` — запуск production-сборки.

## Перед публикацией

- Заменить учебные концепт-проекты на подтверждённые кейсы агентства.
- Заменить демонстрационные карточки команды на реальные профили или убрать секцию.
- Заменить демонстрационный email `hello@northstar.example` и домен `northstar.example` на рабочие.
- Подключить серверный обработчик формы, если нужна реальная отправка заявок. Сейчас форма ничего не отправляет и не сохраняет.
- Обновить `metadataBase`, адрес сайта в `robots.ts` и `sitemap.ts` на подтверждённый production-домен.
